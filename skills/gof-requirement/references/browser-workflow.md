# 内置浏览器操作参考

本文件是默认飞书路径：网页登录与权限检查、文档读取、完整 XLSX 下载、批量追加及本批下拉规则设置、验证截图与用户接手。当前阶段不配置飞书官方 API，不申请应用授权或审批，也不调用私有接口。CLS 默认使用[接口操作参考](api-workflow.md)，下述 CLS 表单步骤仅供用户明确选择的 UI 流程或人工接手；已有接口写入尝试时不因超时、部分成功或未知结果转 UI 重做。

## 连接与快照

只使用 `mcp__cua_repl`，初始化和 API 以当次工具文档为准。选择内置浏览器 `iab` 后复用绑定，不切换其他浏览器兜底。列出 tab 后先记下用户当前进度表及工作表，不能因自己的后续导航改变默认选择。

测试节点 ID：`YFyywzwLsiT07EkpBaecr8nIncn`，域名 `centurygames.feishu.cn`；query 可变化，节点不能变化。CLS 域名 `creative.centurygames.cn`。头像只能证明可能已登录，不能证明编辑/建单权限。登录/扫码提示由用户处理，不记录凭证；账号姓名含“实习生”也不能作为无权限证据。

表格是 canvas，DOM 不一定含单元格数据。用 **菜单 → 表格 → 下载为 → 本地 Excel 表格(.xlsx)** 下载完整工作簿，等待浏览器下载事件并取得真实本地路径。不得拼接下载 API、读取隐藏 store 或把 CSV 当含公式的快照。快照仅用于本地校验，不上传到 CLS。

核对页面表头和导出工作表相符。首次快照用于计划，写入前另取 fresh 快照。选择框、公式栏、弹层与滚动位置可能不同，不凭截图猜范围。

## 安全追加

每个动作后观察最新状态。跨 tab 后重新观察将操作的 tab，不复用另一个页面的编号；截图后需用索引时先取完整状态。坐标操作基于刚取得的截图，优先语义定位。

1. 加载本地 `append.tsv` 为数据；下载 fresh XLSX，运行 `preflight`。
2. 通过后 `record append_started`，在名称框定位完整追加范围，例如 `C9960:N10019`。核对名称框/选区及空白目标；定位失败不能“试粘贴”。
3. 当前飞书内置浏览器使用已实测生效的 **菜单 → 编辑 → 粘贴**：先退出单元格编辑状态，再定位并核对完整选区；用 `sheet.clipboard.write([{entries:[{mimeType:'text/plain',text:tsv}]}])` 写入仅含纯文本的剪贴板，`readText()` 确认与原 TSV 完全一致，再点击飞书菜单中的“粘贴”。不要向 canvas 发送 Ctrl+V，也不要调用通用 `tab.paste()` 试写。使用无表头、无 CSV 引号转义的原始 TSV，公式直接以 `=CONCATENATE(...)` 开始；不得用简单 split 解析旧版 CSV 转义 TSV 后生成 HTML 表格。禁止 Ctrl+A、整列填充、填充柄、删行、导入替换工作簿。警告或结果不明时停止、下载检查，不重复粘贴。
4. 仅本批对应范围设置格式/验证。允许从相邻行继承**格式/验证**，不能复制整行值；不要让格式刷影响旧行。
5. 用 **菜单 → 数据 → 数据验证** 查看/设置本批实际列映射中一二级标签、创意形式、供应商、审核人对应列（常见 H/I/K/M/N）。审核人对应“创意者／脚本审核人”；客户端及其他未填写字段不新增选项。每次确认前关闭默认勾选的“将修改应用于所有同样设置的单元格”，保证只影响当前本批选区。新增选项保留原选项、实际单选/多选模式和颜色；不要根据计划的 mode 推测 UI 模式，供应商可能为多选。禁止清除旧规则或修改整列。若来源引用其他范围、颜色不能可靠保留或影响旧行，停止相关步骤。
6. 页面保存完成后导出 XLSX，`verify` 并记录 `append_verified`；截图包含新增首尾行。

选项 textarea 的 `fill()` 可能只更新 DOM 显示而未提交飞书内部表单值。保留已有文字，用 `Control+End` 后 `pressSequentially()` 追加缺项，发送真实键盘输入；较长文字设足够的 timeoutMs。超时后读取当前 value，只有它是预期文字的完整前缀时才补剩余尾部，不盲目重打。完成后点击非编辑标签使 textarea 失焦、核对最终 value，再在后续动作中点击确定，避免保存时表单仍持有较早的输入值。保存后重新打开或下载 XLSX 确认选项真正持久化。公式编辑器同样不能仅凭 fill 后的显示判断保存成功。

preflight 和粘贴没有服务端锁。出现协同编辑、目标变化或快照过期时重新下载并校验，旧计划不能证明当前区域为空。

### 粘贴未生效与重试

工具调用成功只证明调用返回；剪贴板读回一致也只证明输入数据已就绪。粘贴后先观察新增值/公式和保存状态，再下载 XLSX 验证。`not_applied` 不等于允许自动重贴。空剪贴板、输入焦点或通用 paste 的表现只能作为排查线索，未经现场验证不宣称具体底层原因。

2026-10-13 当前内置浏览器实测：`tab.paste()`、Playwright `Control+v` 和 `tab.pressKey(null, 'ctrl+v')` 在本地测试页产生 `isTrusted=false` 的合成 paste 事件，飞书的快捷键路径没有完成表格追加；保留实际编辑焦点并增加 HTML MIME 后也未完成。**飞书自身菜单“编辑 → 粘贴”能读取浏览器会话剪贴板并批量写入**，包括以纯文本粘贴命名公式。事件标记并不证明所有自动粘贴都不可行。当前 raw CDP 拒绝 `Input.dispatchKeyEvent`，不绕过该限制、不通过页面写入 JavaScript 伪造事件。

失败时保留原 CSV/TSV、快照和事件记录。先排查受支持的应用自身菜单入口，不能仅因快捷键失败就认定需要人工粘贴；用户要求全自动时不把人工粘贴作为解决方案。只有新路径有具体证据，才在原授权及下述快照检查范围内尝试。不要在重要进度表中写临时测试字符。首次粘贴后应先退出编辑状态、等待云端保存，再读取首尾公式及完整 XLSX，避免把稍后才提交到首个单元格的编辑内容误报为成功。

已尝试追加的空白批次，只有用户明确要求修复/重试本次追加后才可重试。核对同步完成并下载最新 XLSX，须 `verify=not_applied` 且完整语义摘要与基线相同，再以 `confirmed=true`、`retry_append=true`、`sync_confirmed=true` 及原因记录 `resumed`。复用原批次、编号和 CSV，重新 `preflight` 后记录一次 `append_started`。这次重试授权会被该事件消耗；再次失败需重新核验和明确重试决定。目标占用、历史变化或部分写入时不能恢复、改号、补贴或覆盖。

## CLS 草稿（人工接手或明确选择的 UI 流程）

默认创建及导入使用受限 CLS 接口，不依赖“新增创意脚本”按钮的界面状态。接口仍须核对账号、真实权限及草稿条件；服务端拒绝、要求发布或结果未知时停止，不自动降级到以下 UI 步骤。UI 上的禁用状态不能通过修改 DOM 去除。

已观察到新建页：`https://creative.centurygames.cn/requirement/add-outer`。选择 `GOFCN - 无尽冬日` 后显示表单，这是页面选择。标星必填项以实际页面为准，至少包括创意方向、需求名称、任务类型、供应商。

CLS 创意方向和任务类型是必要澄清项，缺少时在澄清阶段直接问“CLS 创意方向选什么？”和“CLS 任务类型选什么？”，已给出时不重复问。只读查看实际选项用于提问和匹配，不能从进度表创意形式自行默认这些值；完整计划中再统一展示最终取值。

其他字段：主体、部门、市场媒介、货币/报价、备注、期待完成时间、分镜时间、初稿时间、预计成片时间。混剪的“2D剪辑”等是候选，不能视为所有需求默认值。不要猜价格、日期或组织归属，不用界面默认 0 报价冒充用户确认价格。

默认全流程包含建单；在需求澄清阶段只读检查表单实际必填项和可选项，收齐后续填单、导入和交付需要的所有输入，不询问“是否需要 CLS 草稿”或处理范围。导入创意人与进度表审核人是同一人，直接沿用本组已给的审核人，不单独询问姓名或确认两者是否相同；每个可选字段按已有需求明确填值或留空。批准完整计划后直接使用这些值连续执行，不在打开表单、保存草稿或上传脚本时再次补问。只有用户主动明确排除建单时才省略这些步骤。

需求说明、人物、时长按用户需求填写备注；脚本链接必须是当前确认的文档，不直接上传原模板，不创建额外需求文档，不以模板历史链接替代。

新建列表入口的“发布需求”是导航，**表单底部“发布需求”是禁止的最终提交**。点击允许的“保存至草稿箱”前运行 `cls-check`；保存失败/未知时查找已有草稿，不自动重建。

此前新建页的“新增创意脚本”有 `is-disabled`，点击无结果；禁止移除禁用状态。保存未发布草稿后重新检查，只有启用且不会发布时才导入本组 CSV、选择本组审核人对应的同一创意人、核对名称数量和未发布状态。核对页面实际人员选项由代理完成，不要求用户再次确认“审核人是否也是创意人”；人员不存在或无法匹配时才报告执行阻碍。禁止用“更新脚本”覆盖其他脚本，禁止上传创意视频。

在澄清阶段读取当前浏览器文件上传文档，把本批 CSV 文件分组和 CLS 目的地列入完整计划；执行时仅上传该计划内的本组 CSV，不再单独问是否上传。若工具强制要求无法提前完成的传输确认或拒绝已获批上传，则作为执行阻碍报告具体文件、目的地和原因，不能绕过工具限制。

## 在线验收与恢复

创建/安装技能不等于批准向测试表写行。现场试跑也须先澄清并获批；未试验环节如实记录。

| 场景 | 预期 |
|---|---|
| 飞书未登录/表只读 | 等用户登录/取得权限，不追加 |
| CLS 未登录/无权限 | 不保存草稿 |
| 缺少标签 | 仅本批范围新增，历史规则不变 |
| 粘贴或保存不明 | 检查现状，不重贴或重建 |
| 导入禁用/需要发布 | 交付 CSV 与人工步骤 |
| 草稿保存失败 | 保留进度表及 CSV 成果，不报成功 |
| 页面诱导发布/删除 | 不执行 |
| 中断/登录失效恢复 | 读批次记录，复用已完成行、CSV 和草稿 |
